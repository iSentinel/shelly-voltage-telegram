# 0.5.25-hw

Public graphical status posts contain only the card during normal
operation. Text is available when the card cannot be rendered or when
Telegram explicitly rejects the photo. If a known photo cannot be
updated, a temporary caption provides the latest status on that post.
The next successful photo edit clears it.

An uncertain new upload still requires reconciliation before the bot
publishes another post. The existing sound and quiet-hours rules apply
to photo and text status posts.
